## Release scope

This release ships the OSCAR DUT design sources — schematic, layout, GDS,
netlists, LVS and test files — together with the full rebuild flow. Non-DUT
macros and the largest layout dumps are left out of the tree, which keeps the
release compact while preserving every DUT cell and the complete rebuild path.
