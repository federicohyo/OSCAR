to call upon the function use the following syntax:
python3 capture_variables.py <filename> <process>
Where the filename is equal to the .sch and .mag file.
e.g. for a dpi_syn.sch i would use dpi_syn as the filename
process is either lvs, pex or rcx.

lvs will automatically create the lvs.spice in the lvsspice folder and output the comp.out
